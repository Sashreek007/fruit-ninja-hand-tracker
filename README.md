🎮 Balloon Popper (Real-Time Hand Tracking Game)

Built a real-time Balloon Popper game using hand tracking, with gesture-based controls for pause, resume, and restart.

Added multiple balloon types with unique effects: bonus points, score penalties, extra lives, bombs, and a Dead Eye slow-motion mode.

Implemented dynamic difficulty scaling, combo scoring, and adaptive spawn rates to keep gameplay challenging and engaging.

Runs on mac/linux

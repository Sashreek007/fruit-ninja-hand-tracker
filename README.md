🎮 Balloon Popper (Real-Time Hand Tracking Game)

Built a real-time Balloon Popper game using hand tracking, with gesture-based controls:

✌️ Peace sign → Pause game

👍 Thumbs up → Resume game

🖐️ High five (all five fingers shown) → Restart game

Designed multiple balloon types with unique effects: bonus points, score penalties, extra lives, bombs, and a Dead Eye slow-motion mode.

Implemented dynamic difficulty scaling, combo scoring, and adaptive spawn rates for engaging gameplay.

Runs on mac/linux
